## 📂 Estrutura dos Projetos

| Pasta / Projeto | Descrição Principal |
| :--- | :--- |
| **`01-sql-vs-nosql`** | Conceitos fundamentais, Teorema CAP, ACID/BASE, OLTP vs OLAP e exemplos de consultas em SQL, MongoDB, Redis e Cassandra. |
| **`02-ecommerce-logico`** | Projeto lógico de E-commerce com script de esquema relacional (`01_schema.sql`), massa de dados (`02_dados.sql`) e consultas avançadas (`03_queries.sql`). |
| **`03-oficina-logico`** | Projeto lógico de Oficina Mecânica estruturado com gestão de ordens de serviço, peças, equipes e consultas analíticas. |
| **`04-oficina-conceitual`** | Modelagem conceitual da oficina com Diagrama ER, identificação de entidades, cardinalidades e suposições de negócio. |
| **`05-ecommerce-conceitual`** | Modelagem conceitual refinada do EER para E-commerce (Clientes PF/PJ, múltiplos pagamentos e rastreio de entregas). |
