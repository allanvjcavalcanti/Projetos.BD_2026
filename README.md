# Projetos BD — Banco de Dados

Database Projects | Repositório com 5 projetos de modelagem e consultas SQL/NoSQL

## 🇧🇷 Sobre o projeto

Este projeto consiste no desenvolvimento e documentação de 5 módulos práticos de bancos de dados, abrangendo desde comparações conceituais até a criação de schemas relacionais e consultas complexas.

A aplicação/repositório inclui modelagem conceitual (ER/EER), modelagem lógica, scripts DDL/DML para MariaDB/MySQL e estudo comparativo com tecnologias NoSQL.

### 🎯 Conteúdo dos Projetos

* **01-sql-vs-nosql:** Estudo comparativo entre bancos relacionais e não-relacionais, Teorema CAP, modelos ACID/BASE, OLTP vs OLAP e exemplos práticos em SQL, MongoDB, Redis e Cassandra.
* **02-ecommerce-logico:** Schema relacional para E-commerce com scripts SQL de criação de tabelas, inserção de dados e 13+ queries analíticas (JOINs, GROUP BY, HAVING).
* **03-oficina-logico:** Projeto lógico para gestão de Oficina Mecânica com ordens de serviço, peças, equipes de mecânicos e consultas de desempenho.
* **04-oficina-conceitual:** Diagrama Entidade-Relacionamento (ER) da Oficina Mecânica detalhando entidades, cardinalidades e regras de negócio.
* **05-ecommerce-conceitual:** Diagrama Entidade-Relacionamento Estendido (EER) refinado para E-commerce, contemplando clientes PF/PJ, pagamentos e rastreio de entregas.

### 🛠️ Tecnologias utilizadas

* **MariaDB / MySQL** (SQL Relacional)
* **MongoDB, Redis, Cassandra** (Exemplos NoSQL)
* **Mermaid.js / ERD** (Modelagem Conceitual e Diagramas)
* **Git / GitHub** (Controle de Versão)

## 🇺🇸 About the project

This project consists of the development and documentation of 5 practical database modules, ranging from conceptual comparisons to the creation of relational schemas and complex queries.

The repository includes conceptual modeling (ER/EER), logical modeling, DDL/DML scripts for MariaDB/MySQL, and a comparative study with NoSQL technologies.

### 🎯 Project Content

* **01-sql-vs-nosql:** Comparative study between relational and non-relational databases, CAP Theorem, ACID/BASE models, OLTP vs OLAP, and practical examples in SQL, MongoDB, Redis, and Cassandra.
* **02-ecommerce-logico:** Relational schema for E-commerce with SQL scripts for table creation, data insertion, and 13+ analytical queries (JOINs, GROUP BY, HAVING).
* **03-oficina-logico:** Logical project for Mechanical Workshop management featuring work orders, parts, mechanic teams, and performance queries.
* **04-oficina-conceitual:** Entity-Relationship (ER) Diagram for the Mechanical Workshop detailing entities, cardinalities, and business rules.
* **05-ecommerce-conceitual:** Refined Extended Entity-Relationship (EER) Diagram for E-commerce, covering Individual/Corporate clients, payment methods, and tracking.
