# Desafios de banco de dados

Cinco projetos sobre modelagem e consulta de bancos de dados: teoria de SQL e NoSQL, e modelagem conceitual e lógica de dois cenários (e-commerce e oficina mecânica).

| Pasta | Conteúdo |
|---|---|
| `01-sql-vs-nosql` | Anotações sobre SQL e NoSQL para engenharia de dados |
| `02-ecommerce-logico` | Modelo lógico do e-commerce, com scripts SQL |
| `03-oficina-logico` | Modelo lógico da oficina, com scripts SQL |
| `04-oficina-conceitual` | Modelo conceitual da oficina |
| `05-ecommerce-conceitual` | Modelo conceitual refinado do e-commerce |

Cada pasta funciona sozinha e pode virar um repositório próprio.

Os scripts foram testados em MariaDB 10.11 e devem rodar em MySQL 8.0.16 ou superior.
